Kenapa token cepat habis?
🔁

Claude membaca ulang seluruh percakapan setiap pesan

Setiap kali kamu kirim pesan baru, Claude baca dari awal semua chat. Makin panjang percakapan = makin boros. Ini alasan utama token cepat habis.

🏗️

Buat file di Cowork jauh lebih boros dari sekedar chat

Membuat dokumen Word, Excel, PowerPoint lewat Cowork menggunakan token jauh lebih banyak daripada sekadar bertanya di Chat biasa.

Tips hemat — khusus pengguna Cowork
📋

Rencanakan dulu di Chat, baru buat di Cowork Paling penting

Diskusikan struktur, bagian, dan isi dokumen di Chat biasa dulu. Setelah yakin apa yang kamu mau, baru buka Cowork dan bilang "Buat file ini sesuai rencana tadi."

✗ Buka Cowork → "Buatkan saya laporan keuangan"
✓ Chat dulu → sepakati isinya → Cowork → "Buat file ini persis seperti yang kita bahas"
✏️

Edit prompt lama, jangan kirim pesan baru untuk koreksi

Kalau hasilnya kurang tepat, klik tombol edit di pesan awalmu dan perbaiki di sana. Jangan kirim pesan tambahan seperti "ubah bagian ini" — itu memaksa Claude membaca ulang semua chat dari awal.

💬

Buat chat baru untuk topik yang berbeda

Satu topik = satu percakapan. Jangan campur semua pekerjaan dalam satu chat panjang. Chat yang panjang = Claude kerja lebih keras membaca semuanya setiap pesan.

🎯

Prompt yang spesifik lebih hemat Sering diabaikan

Prompt samar → Claude menebak-nebak → hasilnya salah → kamu kirim lagi → boros. Prompt yang jelas dan spesifik langsung menghasilkan jawaban tepat di percobaan pertama.

✗ "Perbaiki ini" / "Ubah tonenya"
✓ "Tulis ulang intro ini agar terdengar lebih santai, maks 3 kalimat"
⏰

Bagi sesi kerja sepanjang hari, jangan habis pagi semua

Claude punya batas token per jendela 5 jam. Kalau kamu pakai semua di pagi hari, kamu harus nunggu. Bagi pekerjaan berat menjadi 2–3 sesi di waktu berbeda.

📝

Upload file sebagai teks/markdown, bukan PDF besar

Saat mau upload dokumen ke Claude, copy teksnya lalu simpan sebagai file .md (markdown) atau .txt. File teks jauh lebih ringan dibaca Claude dibanding PDF.

🚫

Jangan minta "buat ulang semua" — minta edit bagian tertentu

Kalau ada satu bagian yang kurang, jangan minta Claude menulis ulang seluruh dokumen. Tunjuk bagian mana yang perlu diubah secara spesifik.
